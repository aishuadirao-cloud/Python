1. Scenario: A user is required to enter a valid number in a form, but users sometimes input invalid data. 
Write logic to repeatedly prompt the user until they enter a valid integer
Ans: 
1. Ask input from the user
2. Check the type of input. Check whether its a valid integer.
3. If different datatype is inputted or invalid int is inputted throw error
4. Repeat step 1 to 3 until success.

2. Scenario:A data analysis tool processes a list of numbers and needs to identify the most frequent occurring value.
Write logic to find the most frequently occurring number in a given list 
Ans: 
1. Get the list of numbers
2. Check the occurrence of each number and store it.
3. Verify which number is occurring the max and return the same. 

3. Scenario: A Text processing Application needs to compare words and check if they are anagrams(contain the same letters in a different order)
Write logic to determine whether two given strings are anagram.
Ans:
1. Get both the strings
2. Check the length of both the string. if it is different then return not anagram
3. If they are same length, then check the occurrance of each char of string 1 in string 2 
4. If 1 char also not available then return not anagram
5. IF all the condition satisfies then return both the string are anagram.

4. Scenario: A speech analysis program needs to count the number of vowel sound in a given input

7. Scenario:
An ATM machine processes withdrawal requests and needs to ensure that the users cannot withdraw more than their account balance. 
Write logic to allow a withdrawal only if the balance is sufficient
Ans
1. Get the withdrawal amount
2. Check against the available balance 
3. If withdrawal amount is greater than the available balance then return false and come out 
4. Else proceed with the withdrawal process.
